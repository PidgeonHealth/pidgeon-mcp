# Contributing

Thanks for your interest in improving Pidgeon. This repository is a public release
mirror: it is published from an upstream development source, and accepted changes are
merged upstream and flow back out on the next release. Pull requests and issues are
welcome here.

## Developer Certificate of Origin

Contributions to this project are accepted under the [Developer Certificate of Origin
(DCO) 1.1](DCO). The DCO is a lightweight statement that you wrote the change, or
otherwise have the right to submit it under the project's license. There is no separate
contributor license agreement to sign.

To certify your contribution, add a `Signed-off-by` line to each commit message with your
real name and an email address you can be reached at:

```
Signed-off-by: Jane Developer <jane@example.com>
```

`git commit -s` (or `--signoff`) adds this line for you. By signing off you agree to the
terms in the [`DCO`](DCO) file. Commits without a sign-off cannot be merged.

## What to expect

- Keep pull requests focused and describe the change and its motivation.
- New code should build and pass the repository's tests before review.
- Security issues must not be filed as public issues — see [`SECURITY`](SECURITY.md).
